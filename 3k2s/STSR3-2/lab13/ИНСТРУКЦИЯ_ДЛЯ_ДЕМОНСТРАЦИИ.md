# Инструкция по демонстрации лабораторной работы 13

## Общие требования
- Открыть терминал в папке `lab13`.
- Должен быть установлен Node.js.
- Запускать каждый сервер в отдельном терминале.
- Клиенты запускаются в отдельных терминалах для наглядности.

---

## Оценка выполненности по документу
- Задание 01: реализованы `13-01.js` (TCP-сервер) и `13-02.js` (TCP-клиент).
- Задание 02: реализованы `13-03.js` (TCP-сервер суммирования) и `13-04.js` (TCP-клиент).
- Задание 03: реализованы `13-05.js` (TCP-сервер с индивидуальными суммами) и `13-06.js` (TCP-клиент с параметром X).
- Задание 04: реализованы `13-07.js` (TCP-сервер на портах 40000 и 50000) и `13-08.js` (TCP-клиент с указанием порта).
- Задание 05: реализованы `13-09.js` (UDP-сервер) и `13-10.js` (UDP-клиент).
- Задание 06 (теория): в данной папке явных ответов на вопросы нет.

> Примечание: C++-версии серверов и клиентов, указанные в заданиях 1 и 5, в текущей JavaScript-реализации отсутствуют.

---

## Демонстрация задания 01
1. Терминал 1: `node 13-01.js`
2. Терминал 2: `node 13-02.js`
3. Ожидаемый результат:
   - в терминале сервера появится сообщение о подключении и полученных данных.
   - в терминале клиента появится строка `ECHO: Hello\0`.

---

## Демонстрация задания 02
1. Терминал 1: `node 13-03.js`
2. Терминал 2: `node 13-04.js`
3. Терминал 3: `node 13-04.js`
4. Ожидаемый результат:
   - сервер принимает 32-битовые числа от клиентов.
   - каждые 5 секунд сервер отправляет промежуточную сумму клиентам.
   - клиенты выводят полученные промежуточные суммы и автоматически завершаются через 20 секунд.

---

## Демонстрация задания 03
1. Терминал 1: `node 13-05.js`
2. Терминал 2: `node 13-06.js 2`
3. Терминал 3: `node 13-06.js 5`
4. (Дополнительно) Терминал 4: `node 13-06.js 7`
5. Ожидаемый результат:
   - сервер ведёт диагностические сообщения о подключениях и суммах по каждому клиенту.
   - каждый клиент отправляет одно и то же число X каждую секунду.
   - сервер отправляет каждому клиенту его промежуточную сумму каждые 5 секунд.

---

## Демонстрация задания 04
1. Терминал 1: `node 13-07.js`
2. Терминал 2: `node 13-08.js 40000 1`
3. Терминал 3: `node 13-08.js 50000 2`
4. Ожидаемый результат:
   - сервер слушает порты 40000 и 50000 одновременно.
   - каждый клиент подключается к своему порту и отправляет 32-битовые числа.
   - сервер возвращает каждому клиенту сообщение с префиксом `ECHO:`.

---

## Демонстрация задания 05
1. Терминал 1: `node 13-09.js`
2. Терминал 2: `node 13-10.js`
3. Ожидаемый результат:
   - UDP-сервер принимает строку от клиента.
   - сервер в ответ отправляет строку с префиксом `ECHO:`.
   - клиент выводит полученный ответ и закрывает сокет.

---

## C++ версии (папка СPP013)
Реализованы C++-версии для заданий 01 и 05 (TCP и UDP версии) с использованием WinSock2 для Windows.

### Компиляция C++ приложений
```bash
# Задание 01
cl /EHsc Server01.cpp /link ws2_32.lib
cl /EHsc Client01.cpp /link ws2_32.lib

# Задание 05
cl /EHsc Server05.cpp /link ws2_32.lib
cl /EHsc Client05.cpp /link ws2_32.lib
```

Или через командную строку разработчика Visual Studio:
```bash
cl /EHsc Server01.cpp ws2_32.lib
cl /EHsc Client01.cpp ws2_32.lib
```

### Демонстрация C++ версии задания 01
1. Терминал 1: `Server01.exe`
2. Терминал 2: `Client01.exe`
3. Ожидаемый результат: сервер получает "Hello" и отправляет "ECHO: Hello"

### Демонстрация C++ версии задания 05
1. Терминал 1: `Server05.exe`
2. Терминал 2: `Client05.exe`
3. Ожидаемый результат: сервер получает "Client message" и отправляет "ECHO:Client message"

## Замечания и недостатки
- C++-версии реализованы для заданий 1 и 5 (папка СPP013). Для заданий 2–4 используются JavaScript версии.
- Нет файла с ответами на теоретические вопросы задания 06.
- В `13-05.js` возможно некорректное суммирование данных, если одно сообщение читается более одного раза.

## Рекомендации для преподавателя
- Проверять демонстрацию по каждому шагу последовательно.
- Убедиться, что серверы запущены до запуска клиентов.
- Для задачи 03 попросить запустить два или три клиента с разными значениями X.
- Если потребуется, дополнительно запросить студенту объяснения схемы TCP/UDP и термины `порт`, `сокет`, `дуплекс/полудуплекс`.
