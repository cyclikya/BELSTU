# 🚀 БЫСТРЫЙ СТАРТ ЛАБ 11

## 1️⃣ Установка зависимостей

```bash
npm install
```

## 2️⃣ Запуск ЕДИНОГО сервера (РЕКОМЕНДУЕТСЯ!)

В одном окне терминала:
```bash
node unified-server.js
```

Этот сервер запустит ВСЕ 7 заданий на разных портах одновременно!

## 3️⃣ Запуск клиентов

В отдельных окнах терминала вы можете запускать:

### Задание 1: Загрузка файла
```bash
node c-11-1.js
```

### Задание 2: Скачивание файла
```bash
node c-11-2.js
```

### Задание 3: Ping/Pong (можно несколько)
```bash
node c-11-3.js
node c-11-3.js  # в отдельном окне
```

### Задание 4: JSON-RPC обмен
```bash
node c-11-4.js
```

### Задание 5: RPC функции (выбрать один вариант)
```bash
node c-11-5.js                # только public функции (protected недоступны без логина)
# ИЛИ
node c-11-5login.js           # с аутентификацией (логин: gdv, пароль: 28)
# ИЛИ
node c-11-5expression.js      # вычисление выражения
# ИЛИ
node c-11-5parallel.js        # параллельные вызовы
```

### Задание 6: События (запустить несколько)
```bash
node c-11-6a.js   # слушает событие A
node c-11-6b.js   # слушает событие B
node c-11-6c.js   # слушает событие C
```

### Задание 7: Интерактивные команды
```bash
node c-11-7.js
```

## 📊 Структура сервера unified-server.js

| Порт | Назначение | Задание |
|------|-----------|---------|
| 4000 | RPC функции | 3, 4, 5 |
| 4001 | WebSocket загрузка | 1 |
| 4002 | WebSocket скачивание | 2 |
| 4003 | JSON-RPC обмен | 4 |
| 5000 | RPC события | 6, 7 |
