# Инструкция для демонстрации Лабораторной работы 12
## RESTful API для управления списком студентов

---

## 📋 Описание проекта

Реализован **полнофункциональный RESTful API сервер** на Node.js с поддержкой:
- ✅ CRUD операций (Create, Read, Update, Delete)
- ✅ Управления резервными копиями
- ✅ WebSocket уведомлений при изменении данных
- ✅ Обработки ошибок и валидации данных

---

## 🔧 Подготовка к демонстрации

### Шаг 1: Убедиться в наличии зависимостей

```bash
npm list ws
```

Если пакет **ws** не установлен, установите его:

```bash
npm install ws
```

### Шаг 2: Проверить структуру файлов

В папке lab12 должны быть следующие файлы:
- `lab12.js` - основной сервер с API
- `lab12_client.js` - WebSocket клиент для получения уведомлений
- `StudentList.json` - база данных со студентами
- `postman.json` - коллекция примеров запросов (Postman)
- `backups/` - папка для хранения резервных копий (создается автоматически)

### 📌 REQUEST 3: Добавить нового студента
**POST ⬅️ HTTP метод**
```
POST http://localhost:3000/
Content-Type: application/json

{
    "id": 4,
    "name": "Елена Смирнова",
    "bday": "1998-01-08",
    "specility": "ХТиТ"
}
```

**Ожидаемый результат (201 Created):**
```json
{
    "id": 4,
    "name": "Елена Смирнова",
    "bday": "1998-01-08",
    "specility": "ХТиТ"
}
```

**curl команда:**
```bash
curl -X POST http://localhost:3000/ ^
  -H "Content-Type: application/json" ^
  -d "{\"id\": 4, \"name\": \"Елена Смирнова\", \"bday\": \"1998-01-08\", \"specility\": \"ХТиТ\"}"
```

**Проверка: Попытка добавить студента с существующим ID**
```bash
curl -X POST http://localhost:3000/ ^
  -H "Content-Type: application/json" ^
  -d "{\"id\": 1, \"name\": \"Новое имя\", \"bday\": \"1998-01-08\", \"specility\": \"ХТиТ\"}"
```

**Ожидаемый результат (400 Bad Request):**
```json
{
    "error": 4,
    "message": "Студент с id 1 уже существует"
}
```

**⚠️ WebSocket уведомление:** После добавления нового студента клиент должен получить:
```
Уведомление: StudentList.json был обновлён
```

### 📌 REQUEST 6: Создать резервную копию
**POST ⬅️ HTTP метод**
```
POST http://localhost:3000/backup
```

⏳ **Внимание:** Запрос выполняется 2 секунды (setTimeout)

**Ожидаемый результат (201 Created):**
```json
{
    "message": "Backup created",
    "backup_file": "20260429120534_StudentList.json"
}
```

**curl команда:**
```bash
curl -X POST http://localhost:3000/backup
```

**В папке `backups/` будет создан файл** с именем:
```
YYYYMMDDHHMMSS_StudentList.json
Пример: 20260429120534_StudentList.json
```

### 📌 REQUEST 8: Удалить устаревшие резервные копии
**DELETE ⬅️ HTTP метод**
```
DELETE http://localhost:3000/backup/14042026
```

Этот запрос удаляет все резервные копии **ДО 14 апреля 2026 года**

**Формат даты:** `YYYYDDMM` (год + день + месяц)
- `20260429` → 29 апреля 2026 года
- `14042026` → 14 апреля 2026 года (месяц = 04, день = 14, год = 2026)

**Ожидаемый результат (200 OK):**
```json
{
    "message": "устаревшие бэкапы были удалены",
    "deleted_count": 2
}
```

**curl команда:**
```bash
curl -X DELETE http://localhost:3000/backup/14042026
```

**Проверка: Запросить некорректную дату**
```bash
curl -X DELETE http://localhost:3000/backup/32022026
```

**Ожидаемый результат (400 Bad Request):**
```json
{
    "error": 2,
    "message": "Некорректная дата (дня не существует)"
}
```

## 🛠️ Помощь при проблемах

**Проблема:** Порт 3000 уже занят
```bash
netstat -ano | findstr :3000
taskkill /PID <PID> /F
```

**Проблема:** Модуль ws не найден
```bash
npm install ws
```

**Проблема:** WebSocket клиент не подключается
- Убедитесь, что сервер запущен
- Проверьте, что используется правильный адрес `ws://localhost:3000`

Этот файл является основной базой данных. Его структура:

```json
[
    {
        "id": <unique_number>,
        "name": "<student_name>",
        "bday": "<YYYY-MM-DD>",
        "specility": "<specialty>"
    }
]
```

Все операции (CREATE, UPDATE, DELETE) сохраняют изменения в этот файл.
