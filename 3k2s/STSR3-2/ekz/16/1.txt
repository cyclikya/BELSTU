//1. ASP.NET CORE: назначение, основные свойства, кроссплатформенность, общая структура приложения, маршрутизация, типы приложений ASP.NET CORE, программный менеджер NuGet, встроенные компоненты.  

.NET Core — это платформа для разработки ПО (по сути фреймворк). Платформа = набор библиотек и инструментов для разработки. 
Её главные свойства: кроссплатформенность и открытый код.

1. Назначение
ASP.NET Core — программная платформа от Microsoft для разработки web-приложений на основе .NET Core. 
То есть это надстройка над .NET Core именно под веб.

2. Основные свойства
    - фреймворк с открытым кодом;
    - может работать как над .NET Core, так и над полной .NET;
    - модульность — компоненты подключаются по отдельности через NuGet, не нужна тяжёлая System.Web.dll;
приложения работают под IIS (Windows) или под кроссплатформенным веб-сервером Kestrel.

3. Кроссплатформенность
Это главная особенность. Достигается за счёт того, что для разных ОС существуют свои версии платформы (CoreCLR + CoreFX машинозависимы и собраны под каждую ОС).
Кроссплатформенность бывает двух видов:
    - на уровне исходного кода — надо перекомпилировать под каждую ОС (пример — библиотека Qt для C++);
    - на уровне байт-кода — под каждую ОС пишут свой интерпретатор/библиотеки (например, свой CLR). 
.NET Core — это как раз второй вариант.



//3. Разработка клиент-серверного приложения  с применением технологии WebAssembly на стороне браузера. 

WebAssembly (сокращённо WASM) — это низкоуровневый бинарный формат кода, который выполняется в браузере почти со скоростью нативного кода.

Главная идея и проблема, которую он решает: в браузере единственный язык — JavaScript, но он интерпретируемый и для тяжёлых вычислений (графика, обработка видео, игры, математика) медленноват. 
WebAssembly позволяет писать такие тяжёлые части на быстрых языках (C, C++, Rust), компилировать их в бинарный .wasm-модуль и запускать прямо в браузере. JavaScript при этом никуда не девается — он вызывает функции из wasm-модуля.
Ключевые свойства:
    - бинарный формат (компактный, быстро парсится);
    - высокая скорость выполнения (близко к нативной);
    - не замена JavaScript, а дополнение — работают вместе: JS управляет, WASM считает тяжёлое;
    - кроссбраузерность — поддерживается всеми современными браузерами.



На стороне браузера: сервер отдаёт .wasm-файл как статику. В браузере 
JavaScript загружает его: WebAssembly.instantiateStreaming(fetch('/add.wasm'))
скачивает и компилирует модуль, а через instance.exports.add вызывает
экспортированную из модуля функцию. Вычисление выполняет WASM, а не JS.»
