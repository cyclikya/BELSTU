//1. DOM, BOM: определение и назначение.

Сначала контекст — откуда вообще берутся DOM и BOM. Браузер — это прикладное средство, которое формирует HTTP-запросы, получает и обрабатывает ответы, отображает файлы и интерпретирует JavaScript. Чтобы JavaScript мог управлять браузером и страницей, браузер представляется программисту в виде трёх моделей: BOM, DOM и Browser API. DOM и BOM — это как раз две из них, и вопрос именно про них.
Проще говоря: JavaScript сам по себе ничего не знает ни о странице, ни о браузере. DOM и BOM — это «мостики», через которые JS добирается до содержимого страницы (DOM) и до самого браузера (BOM).

DOM (Document Object Model)
    Определение. DOM — это объектная модель документа, которую браузеры используют для представления HTML-документа и взаимодействия с ним.
    Назначение. DOM позволяет JavaScript манипулировать содержимым, структурой и стилями документа. То есть через DOM скрипт может прочитать любой элемент страницы, изменить текст, добавить или удалить элемент, поменять стиль.
    Ключевое слово — document: DOM это всё, что внутри HTML-страницы.

BOM (Browser Object Model)
    Определение. BOM — это объектная модель браузера. Она предоставляет интерфейсы для взаимодействия с самим браузером — вне контекста HTML-документа.
    Назначение. Управлять браузером как окружением: адресной строкой, историей, размером экрана, информацией о браузере. BOM включает объекты:
        - window — само окно браузера (главный, корневой объект);
        - navigator — информация о браузере (название, версия);
        - screen — информация об экране;
        - location — текущий URL (можно прочитать или сменить адрес);
        - history — история переходов (вперёд/назад).
    Ключевое слово — window: BOM это всё, что вокруг страницы, сам браузер.

Главное различие (это и спросят)
    DOM работает с содержимым страницы (документ, HTML-элементы), корневой объект — document.
    BOM работает с самим браузером (окно, история, адрес), корневой объект — window.
Можно сказать так: DOM — «что внутри вкладки», BOM — «сама вкладка и браузер вокруг неё».
