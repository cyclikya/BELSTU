Фрагмент данных (4 KB), который запоминается клиентом по указанию сервера. 
1. Сервер отправляет заголовок Set-Cookie со значением Cookie внутри
2. Клиент обязан в последующих запросах отправлять заголовок Cookie

Главное назначение — сохранение состояния. Конкретные применения:
    - аутентификация (сервер узнаёт залогиненного пользователя);
    - хранение пользовательских предпочтений (язык, тема);
    - статистика;
    - хранение информации о сеансе — обычно это Session ID (идентификатор сессии).

Параметры cookie
У cookie, кроме имени и значения, есть параметры, которые управляют её поведением:
    - Path — для каких URL (эндпоинтов) отправлять cookie;
    - Domain — для какого домена действует cookie;
    - Expires — дата истечения (когда cookie «умрёт»);
    - Max-Age — время жизни в секундах;
    - Secure — отправлять только по HTTPS (защищённое соединение);
    - HttpOnly — запретить доступ к cookie через JavaScript (защита от кражи скриптом);
    - SameSite — контроль межсайтовой отправки (защита от CSRF-атак).
