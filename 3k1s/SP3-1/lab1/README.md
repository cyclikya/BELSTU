# OS10 HT API - Статическая библиотека и приложение

## Структура проекта

```
OS10_01/
├── OS10_01/           # Исходный проект (без DLL)
│   ├── HT.h           # Заголовочный файл API
│   ├── HP.cpp         # Реализация API
│   └── os10_1.cpp     # Тестовое приложение
├── OS10_HTAPI/        # Статическая библиотека
│   ├── HT.h           # Заголовочный файл API
│   └── OS10_HTAPI.cpp # Реализация API для библиотеки
└── OS10_02/           # Приложение, использующее библиотеку
    └── OS10_02.cpp    # Основной файл приложения
```

## Задания выполнены

### 9. Разработана статическая библиотека OS10_HTAPI
- Создана статическая библиотека с HT API
- Убраны все DLL-макросы и extern "C"
- Библиотека содержит все функции для работы с хеш-таблицей

### 10. Разработано приложение OS10_02
- Создано приложение, функционально повторяющее OS10_01
- Приложение использует статическую библиотеку OS10_HTAPI
- Включает те же тесты: создание, вставка, получение, обновление, удаление

### 11. Демонстрация работоспособности
- OS10_02.cpp содержит полный набор тестов
- Тестируется создание и открытие хеш-таблицы
- Проверяются все основные операции с элементами

## Компиляция

### Статическая библиотека OS10_HTAPI
```bash
# Компиляция библиотеки
cl /c OS10_HTAPI/OS10_HTAPI.cpp /Fo:OS10_HTAPI.obj
lib OS10_HTAPI.obj /OUT:OS10_HTAPI.lib
```

### Приложение OS10_02
```bash
# Компиляция с библиотекой
cl /EHsc OS10_02/OS10_02.cpp OS10_HTAPI.lib /Fe:OS10_02.exe
```

## Функции HT API

- `Create()` - создание хеш-таблицы
- `Open()` - открытие существующей хеш-таблицы
- `Insert()` - вставка элемента
- `Get()` - получение элемента
- `Update()` - обновление элемента
- `Delete()` - удаление элемента
- `Snap()` - создание снимка
- `Close()` - закрытие хеш-таблицы
- `GetHTLastError()` - получение последней ошибки
- `Print()` - вывод элемента

## Особенности реализации

1. **Убраны DLL-макросы** - код работает как обычная статическая библиотека
2. **Исправлены конфликты имен** - `GetHTLastError` вместо `GetLastError`
3. **Добавлена диагностика ошибок** - подробные сообщения об ошибках Windows API
4. **Поддержка Unicode** - работа с wchar_t для имен файлов
5. **Потокобезопасность** - использование мьютексов для синхронизации
