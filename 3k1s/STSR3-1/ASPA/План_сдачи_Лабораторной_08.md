## ВОЗМОЖНЫЕ ВОПРОСЫ ПРЕПОДАВАТЕЛЯ И ОТВЕТЫ:

**Вопрос:** "В чем преимущества MVC перед Razor Pages?"
**Ответ:** "MVC обеспечивает лучшее разделение ответственности, более гибкую маршрутизацию, легче тестировать контроллеры отдельно от представлений, и лучше подходит для больших приложений."

**Вопрос:** "Как работает Action Filter?"
**Ответ:** "Action Filter выполняется до и/или после выполнения действия контроллера. В моем случае InfoAsyncActionFilter выполняется до действия, асинхронно получает данные из Wikipedia API и сохраняет их в HttpContext.Items для использования в представлении."

**Вопрос:** "Почему используется асинхронный метод в Action Filter?"
**Ответ:** "Асинхронный метод необходим, так как мы делаем HTTP-запрос к внешнему API (Wikipedia), который может занять время. Использование async/await предотвращает блокировку потока выполнения."

**Вопрос:** "Как передаются данные из контроллера в представление?"
**Ответ:** "Данные передаются через строго типизированные модели (record types), которые передаются в метод View(). Также можно использовать ViewData и ViewBag, но в моем проекте я использую модели для типобезопасности."

**Вопрос:** "Что такое HTML Helper и зачем он нужен?"
**Ответ:** "HTML Helper - это метод расширения для IHtmlHelper, который инкапсулирует логику генерации HTML. В моем случае CelebrityPhoto() генерирует полный HTML-код для изображения с обработчиками событий, что упрощает код представлений и обеспечивает переиспользование."
