# Инструкция по тестированию системы клиент-сервер

## Быстрая справка по сервисам

| Сервис | Команда клиента | Ответ сервера | Завершение |
|--------|----------------|---------------|------------|
| **Rand** | `Rand` (обязательно с большой R) | `Rand: [случайное число]` | Любая другая строка |
| **Time** | `Time` (обязательно с большой T) | `Time dd.mm.yyyy/hh:mm:ss` | Любая другая строка |
| **Echo** | Любая строка | Та же строка обратно | `exit` или таймаут |

**Важно:** 
- Rand и Time чувствительны к регистру - только "Rand" и "Time" (не "rand" или "time")
- Echo принимает любые строки и возвращает их обратно
- Все сервисы завершаются по таймауту (3 минуты по умолчанию)

## Описание сервисов

### 1. Echo Server (Эхо-сервер)
**Функциональность:**
- Принимает любые данные от клиента
- Отправляет те же данные обратно без изменений (эхо)
- Работает до получения команды "exit" или до таймаута (3 минуты)

**Как проверить:**
- Запустите клиента, выберите сервис "3 - Echo"
- Введите любую строку (например: "Hello World", "Test123", "Привет")
- Сервер должен вернуть точно такую же строку
- Для завершения отправьте "exit" или дождитесь таймаута

**Пример работы:**
```
Выбор сервиса: 3
Введите команду: Hello World
Полученное сообщение:[Hello World]
Полученное сообщение:[Hello World]
Полученное сообщение:[Hello World]
... (повторяется до таймаута или "exit")

Введите команду: exit
Полученное сообщение:[Close: finish;]
Сервер завершил соединение: Close: finish;
Время: X.XXX сек.
```

**Примечание:** Клиент отправляет одну команду многократно в цикле, поэтому "Hello World" будет отправляться снова и снова, пока не будет отправлен "exit" или не истечет таймаут.

---

### 2. Time Server (Сервер времени)
**Функциональность:**
- Принимает только команду "Time" (регистр важен!)
- Отвечает текущей датой и временем сервера в формате: `Time dd.mm.yyyy/hh:mm:ss`
- Завершается при получении любой другой строки (не "Time") или по таймауту

**Как проверить:**
- Запустите клиента, выберите сервис "2 - Time"
- Введите команду "Time" (обязательно с большой буквы T)
- Сервер вернет текущее время сервера
- Можно отправлять "Time" многократно - каждый раз получите актуальное время
- Для завершения отправьте любую другую строку (например: "stop", "quit", "end")

**Пример работы:**
```
Выбор сервиса: 2
Введите команду: Time
Полученное сообщение:[Time 15.12.2024/14:30:45]
Полученное сообщение:[Time 15.12.2024/14:30:46]
Полученное сообщение:[Time 15.12.2024/14:30:47]
... (время обновляется при каждом ответе)

(При таймауте через 3 минуты:)
Сервер завершил соединение: Close: timeout;
Время: 180.XXX сек.
```

**Важно:** Клиент автоматически отправляет "Time" в цикле, поэтому время будет обновляться автоматически. Для завершения просто закройте клиента или дождитесь таймаута.

**Важно:** Если отправить "time" (маленькими буквами) или любую другую строку, сервер завершит работу.

---

### 3. Rand Server (Сервер случайных чисел)
**Функциональность:**
- Принимает только команду "Rand" (регистр важен!)
- Отвечает случайным целым числом в формате: `Rand: [число]`
- Завершается при получении любой другой строки (не "Rand") или по таймауту

**Как проверить:**
- Запустите клиента, выберите сервис "1 - Rand"
- Введите команду "Rand" (обязательно с большой буквы R)
- Сервер вернет случайное число
- Можно отправлять "Rand" многократно - каждый раз получите новое случайное число
- Для завершения отправьте любую другую строку (например: "stop", "quit", "end")

**Пример работы:**
```
Выбор сервиса: 1
Введите команду: Rand
Полученное сообщение:[Rand: 18467]
Полученное сообщение:[Rand: 29358]
Полученное сообщение:[Rand: 49231]
... (каждый раз новое случайное число)

(При таймауте через 3 минуты:)
Сервер завершил соединение: Close: timeout;
Время: 180.XXX сек.
```

**Важно:** Клиент автоматически отправляет "Rand" в цикле, поэтому будут генерироваться новые случайные числа. Для завершения просто закройте клиента или дождитесь таймаута.

**Важно:** Если отправить "rand" (маленькими буквами) или любую другую строку, сервер завершит работу.

## Подготовка к тестированию

### 1. Настройка DNS (для теста пункта 6.2)
- Пропишите имя вашего сервера в зоне прямого просмотра DNS
- Например, добавьте запись типа A: `myserver.local` → IP адрес сервера

### 2. Настройка сетевого окружения
- Убедитесь, что у вас есть доступ минимум к 2 компьютерам в одной сети
- Проверьте, что брандмауэры разрешают соединения на используемых портах
- Узнайте IP-адрес сервера и широковещательный адрес сети

### 3. Параметры запуска

**Сервер:**
```
ConcurrentServer.exe [TCP_порт] [UDP_порт] [DLL_имя] [имя_канала] [позывной] [таймаут_секунд]
```
- TCP_порт (по умолчанию: 2000) - порт для TCP соединений
- UDP_порт (по умолчанию: 2000) - порт для UDP широковещательных запросов
- DLL_имя (по умолчанию: Service_Library) - имя библиотеки сервисов
- имя_канала (по умолчанию: cpipe) - имя именованного канала для консоли
- позывной (по умолчанию: HELLO) - позывной для широковещательного поиска
- таймаут_секунд (по умолчанию: 180) - таймаут сервисов в секундах (3 минуты)

**Пример запуска сервера с таймаутом 3 минуты:**
```
ConcurrentServer.exe 2000 2000 Service_Library cpipe HELLO 180
```

**Клиент:**
```
Client.exe
```
- При запуске клиент запросит:
  1. Тип подключения (1 - по DNS имени, 2 - по позывному)
  2. Имя сервера или позывной
  3. Порт сервера
  4. Тип сервиса (1 - Rand, 2 - Time, 3 - Echo)
  5. Команду для отправки серверу

**Важно о командах для сервисов:**
- **Rand**: отправляйте только "Rand" (с большой буквы) для получения случайного числа
- **Time**: отправляйте только "Time" (с большой буквы) для получения времени
- **Echo**: отправляйте любые строки, они будут возвращены обратно; "exit" для завершения

**Примечание:** Клиент отправляет одну команду многократно в цикле. После каждого ответа сервера команда отправляется снова. Для завершения работы сервисов Rand/Time отправьте любую другую строку (но клиент будет продолжать отправлять ту же команду, поэтому лучше просто дождаться таймаута или закрыть клиента).

**Консоль управления (RemoteConsole):**
```
RemoteConsole.exe
```
- При запуске запросит имя сервера
- Доступные команды:
  - 1 - start (разрешить подключение клиентов)
  - 2 - stop (запретить подключение клиентов)
  - 3 - exit (завершить работу сервера)
  - 4 - statistics (вывод статистики)
  - 5 - wait (приостановить подключение клиентов)
  - 6 - shutdown (wait + exit)
  - 0 - закрыть консоль

## Важные замечания

1. **Таймаут:** Убедитесь, что сервер запущен с параметром таймаута 180 секунд (3 минуты)

2. **Сеть:** Для тестирования широковещания убедитесь, что все компьютеры в одной подсети

3. **DNS:** Для теста DNS-имени необходимо настроить DNS-запись заранее

4. **Порты:** Убедитесь, что порты не заняты другими приложениями

5. **Логирование:** Следите за выводом сервера для проверки регистрации подключений и отключений

6. **Время:** Некоторые тесты требуют ожидания (таймаут 3 минуты), планируйте время соответственно

7. **Аварийное завершение:** Для аварийного завершения клиентов используйте:
   - Закрытие окна консоли
   - Диспетчер задач Windows (завершить процесс)
   - Ctrl+C в консоли (если поддерживается)

## Типичные проблемы и решения

1. **Сервис не отвечает или завершается сразу:**
   - **Rand/Time**: Убедитесь, что отправляете команду с правильным регистром ("Rand" или "Time", не "rand" или "time")
   - **Echo**: Проверьте, что отправляете не пустую строку
   - Проверьте, что сервер запущен и клиент подключен

2. **Клиент не находит сервер по позывному:**
   - Проверьте широковещательный адрес в Client.cpp (строка 158)
   - Убедитесь, что UDP порт совпадает на сервере и клиенте
   - Проверьте брандмауэр

2. **Клиент не находит сервер по DNS:**
   - Проверьте DNS-запись
   - Используйте `nslookup` для проверки разрешения имени
   - Попробуйте использовать IP-адрес напрямую

3. **Консоль не подключается:**
   - Проверьте имя сервера (имя компьютера)
   - Убедитесь, что сервер запущен
   - Проверьте права доступа к именованному каналу

4. **Таймаут не срабатывает:**
   - Проверьте параметр таймаута при запуске сервера
   - Убедитесь, что значение в секундах (180 для 3 минут)
